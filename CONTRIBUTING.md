# Contributing to Team Management

Thank you for contributing.

## Development Setup

1. Fork the repository
2. Create a feature branch from `main`
3. Install dependencies:
   - Backend: `cd "Team Management/Hackathon-Tracker/backend" && npm install`
   - Frontend: `cd "Team Management/Hackathon-Tracker/frontend" && npm install`
4. Run backend and frontend locally using `npm run dev`

## Contribution Workflow

1. Create a branch: `git checkout -b feature/short-description`
2. Make focused, minimal changes
3. Validate relevant checks (for example frontend lint/build)
4. Commit with clear messages
5. Open a pull request with:
   - Problem summary
   - What changed
   - How it was tested

## Pull Request Guidelines

- Keep PRs small and focused
- Do not include secrets or credentials
- Update documentation when behavior or setup changes
- Ensure changed functionality is manually verified

## Code of Conduct

Be respectful and constructive in all discussions and reviews.
